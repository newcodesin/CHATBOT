# 🤖 Telegram Registration Bot

A secure and user-friendly Telegram bot that allows users to **register with their email and password**, stores data in an Excel sheet, and includes:

- 🔒 Password hashing (bcrypt)
- 📁 Excel export of registered users
- 👨‍💼 Admin-only access to user data
- ✅ Inbuilt reply keyboard for ease of use

---

## 📦 Features

- `/start` – Show custom keyboard
- `/login` – Register using email & password
- `/logout` – Remove your session (locally)
- `/cancel` – Cancel any ongoing registration
- `/users` – (Admin only) Download user list as `.xlsx`
